# PILGRIM — роадмап MVP (демо)

**Цель:** кликабельное демо MVP сайта-сообщества на GitHub Pages, чтобы заказчик его посмотрел.

**Рамки:** делаем только фронт. Данные берутся из типизированных моков в форме будущего DRF API, поэтому бэкенд потом подключается без переделки UI. Бэкенд и инфраструктура из ТЗ вынесены в отложенный **Этап B**.

## Зафиксированные решения

- Next.js (актуальный stable) + TypeScript, App Router, статический экспорт `output: 'export'`.
- Стили только свои: CSS Modules + CSS-переменные. **Tailwind и UI-библиотеки не используем.**
- Монорепо: `pilgrim_front/` — фронт, `pilgrim_back/` — бэкенд (Этап B).
- Репозиторий публичный, деплой через GitHub Actions → GitHub Pages.
- Язык интерфейса — только русский.

## Правила работы

- Один этап = одна сессия. В конце этапа отмечаем чекбоксы и пишем строку в «Журнал».
- Этап сдаётся, когда зелёные `lint`, `type-check` и `build`. Визуальные правки проверяем в Playwright на 360 / 768 / 1280px: без горизонтального скролла.
- Коммит и пуш — только по команде. Каждую новую зависимость согласуем.
- Комментарии в коде по минимуму, код самодокументируется именами и структурой.

### Хостинг и бюджет — до 450 ₽/мес

Решение от 25.10.2026. Selectel (VDS 1-2-25 / 2-2-40) распродан. Среди альтернатив до 450 ₽ подходящий по памяти и диску вариант — [AdminVPS](https://adminvps.ru/).

| Что | Выбор | Стоимость |
| --- | --- | --- |
| Сервер | AdminVPS **Promo**: 1 × 3,6 ГГц, 2 ГБ RAM, 30 ГБ NVMe, KVM, 3 ТБ трафика, еженедельный бэкап сервера бесплатно | 499 ₽/мес помесячно; **5 090 ₽ за 12 мес. ≈ 424 ₽/мес** (−15% по таблице; в конфигураторе указано −10% → ≈ 449 ₽/мес) |
| Домен `.ru` | у любого регистратора | ≈ 20–25 ₽/мес в пересчёте с годовой оплаты — оценка, сверить у регистратора |
| SSL | Let's Encrypt через Caddy, автопродление | 0 ₽ |
| Бэкапы вне сервера | rclone в бесплатное облако (Яндекс Диск / Облако Mail.ru) | 0 ₽ |
| Донаты | платёжный сервис | только комиссия с платежей |
| **Итого** | | **≈ 445–475 ₽/мес** — в 450 ₽ укладывается только при оплате на год и скидке 15%; при −10% выходит ≈ 470 ₽ |

Запасной вариант — AdminVPS **Lite**: 1 ГБ RAM, 15 ГБ NVMe, 349 ₽/мес помесячно. На нём работаем в экономном режиме: swap 2 ГБ, урезанный PostgreSQL или SQLite (по согласованию с заказчиком), сборка только в CI.

Перед оплатой проверить в конфигураторе и поддержке:
- [ ] публичный IPv4 входит в цену (на странице не указано);
- [ ] процессор гарантированный или общий;
- [ ] итоговую скидку за 12 мес. (на странице расхождение: 15% или 10%);
- [ ] локация — Россия, образ Ubuntu LTS;
- [ ] **первый месяц оплатить помесячно**, проверить скорость и стабильность, затем перейти на годовую оплату.

Бюджет памяти на Promo (2 ГБ): ОС и Docker ~300 МБ, PostgreSQL ~150 МБ, Django ~200 МБ, Caddy ~30 МБ — **≈ 700 МБ**, остальное — запас и кэш.
Бюджет диска (30 ГБ): ОС ~3 ГБ, образы ~1,5 ГБ, база < 1 ГБ — **≈ 20 ГБ под фото**. При WebP-нарезке это десятки тысяч снимков.
