# pilgrim_back

Бэкенд сайта PILGRIM: Django + Django REST Framework + PostgreSQL, управление контентом через админку Django.

Работы запланированы на Этап B (см. [`ROADMAP.md`](../ROADMAP.md)) и начнутся после согласования демо. Контракт API, на который уже рассчитан фронтенд, будет описан в `docs/api-contract.md`.
