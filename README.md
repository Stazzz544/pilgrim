# PILGRIM — походы и приключения

Сайт сообщества PILGRIM: мероприятия и календарь, микроблог, фотогалерея, поддержка проекта и связь с сообществом ВКонтакте.

Сейчас в репозитории **демо-версия MVP**. Это фронтенд, который работает на демонстрационных данных и публикуется на GitHub Pages. Серверная часть (Django REST Framework, админка, PostgreSQL) подключится на следующем этапе, интерфейс при этом переделывать не придётся.

**Демо:** https://stazzz544.github.io/pilgrim/ — ссылка заработает после первой публикации.

## Структура

| Папка            | Что внутри                                                   |
| ---------------- | ------------------------------------------------------------ |
| `pilgrim_front/` | Фронтенд: Next.js + TypeScript, собственные стили без CSS-фреймворков |
| `pilgrim_back/`  | Бэкенд: Django + DRF, следующий этап                         |
| `ROADMAP.md`     | План работ и журнал выполнения                               |

## Запуск фронтенда

Нужен Node.js 24 (версия зафиксирована в `.nvmrc`).

```bash
cd pilgrim_front
npm install
npm run dev        # http://localhost:3000
```

| Команда              | Что делает                                       |
| -------------------- | ------------------------------------------------ |
| `npm run dev`        | Сервер разработки                                |
| `npm run build`      | Статическая сборка в `pilgrim_front/out/`        |
| `npm run lint`       | ESLint                                           |
| `npm run type-check` | Проверка типов TypeScript                        |

Чтобы собрать сайт под подпапку (как на GitHub Pages), задайте префикс: `NEXT_PUBLIC_BASE_PATH=/pilgrim npm run build`.
